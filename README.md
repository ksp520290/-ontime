# Runtime Board（進行表・タイマー管理コンソール）

Ontime（https://github.com/cpvalente/ontime）の主要な画面構成を参考に、
サーバー不要・HTML / CSS / Vanilla JavaScript のみで再構成した
軽量版の進行表・タイマー管理ツールです。

## 含まれる画面

| ファイル          | 役割                                                             |
| ----------------- | ------------------------------------------------------------------ |
| `index.html`      | ホーム。プロジェクト情報、各画面へのリンク、JSON書き出し/読み込み |
| `editor.html`     | 進行表エディタ。イベントの追加・編集・並べ替え・色分け             |
| `operator.html`   | オペレーター画面。再生・一時停止・送り・時間加減・メッセージ送信   |
| `timer.html`      | 客席・登壇者向けの全画面タイマー表示（ダブルクリックで全画面化）   |
| `backstage.html`  | バックステージ・楽屋向け表示。現在＋次の進行キューを一覧表示       |

## 使い方

1. `index.html` をブラウザで開いてください。
2. 「サンプル進行表を読み込む」で動作を確認できます。
3. `editor.html` で本番の進行表を作成します。
4. `operator.html` を操作卓のPCで開き、進行をコントロールします。
5. `timer.html` / `backstage.html` を別ウィンドウ・別画面（客席モニターや
   楽屋モニターなど）で開いておくと、`operator.html` での操作がリアルタイムに
   反映されます。

## データの同期について

- すべてのデータはブラウザの `localStorage` に保存されます（サーバーへの送信は一切ありません）。
- 複数ウィンドウ間の同期はブラウザの `storage` イベントとポーリングの両方で行っています。
  `file://` で直接開いても多くのブラウザで動作しますが、同期の安定性を高めたい場合は、
  このフォルダをローカルサーバーで配信して `http://localhost:xxxx` として開くことを推奨します。
  （例: `npx serve .` や Python の `python3 -m http.server` など）
- 同期対象は同一ブラウザ内の複数タブ/ウィンドウです。別のPC・別デバイス間の同期はできません
  （ネットワーク経由の同期が必要な場合は本家 Ontime のサーバー版をご利用ください）。

## 注意

本ツールは Ontime の実装コードを直接移植したものではなく、公開されている機能・画面構成を
参考にゼロから実装した独立した簡易版です。外部ライブラリやビルドツールを使用しておらず、
このフォルダのファイルをそのまま配布・改変してご利用いただけます。
